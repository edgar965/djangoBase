Vergleich: Werkzeug Code Review gegen Language Server

Beide lesen den Quelltext, aber sie stellen verschiedene Fragen. Das Werkzeug Code Review (Hilfe → Werkzeug Code Review) prüft die Regeln dieses Projekts — Dateigröße, Doppelcode, tote Importe, Vorlagen und Endpunkte, stumme Ausnahmen — mit eigenen Prüfern auf dem Syntaxbaum jeder Datei. Der Language Server prüft, ob der Code zusammenpasst: Gibt es den Namen? Passt der Aufruf zur Signatur? Kann das hier None sein? Dafür löst er Importe, Klassen und Typen über das ganze Projekt auf.
